# CR-121

**Objective:** Add a reusable GitHub-hosted Apple Silicon iOS quality workflow with failure diagnostics.

**Files:** `.github/workflows/ios.yml`, `Infrastructure/ci/tests/validate-workflows_test.sh`

**Steps:**
1. Assert the `macos-26` image, explicit Xcode 26.6 selection, preflight, lint, test, unsigned-build, and timeout requirements.
2. Install pinned tools, boot `iPhone 17`, run existing Make targets, and cancel superseded concurrent runs.
3. Upload failing xcresult diagnostics for seven days and validate locally on the Mac.

**Duration:** 15m

**Dependencies:** CR-116, CR-118

**Parallel:** Yes

**Definition of Done:** The stable `iOS` check runs on a fresh GitHub-hosted VM, performs preflight, strict lint, package and app tests, unsigned build, and retains failure evidence.
