# CR-121

**Objective:** Add a reusable self-hosted iOS quality workflow with failure diagnostics.

**Files:** `.github/workflows/ios.yml`, `Infrastructure/ci/tests/validate-workflows_test.sh`

**Steps:**
1. Assert runner labels, preflight, lint, test, unsigned-build, and timeout requirements.
2. Boot `iPhone 17`, run existing Make targets, and cancel superseded concurrent runs.
3. Upload failing xcresult diagnostics for seven days and validate locally on the Mac.

**Duration:** 15m

**Dependencies:** CR-116, CR-118

**Parallel:** Yes

**Definition of Done:** The stable `iOS` check runs preflight, strict lint, package and app tests, unsigned build, and retains failure evidence.
