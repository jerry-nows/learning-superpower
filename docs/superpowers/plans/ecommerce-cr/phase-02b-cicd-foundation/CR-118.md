# CR-118

**Objective:** Provide one deterministic local validator for workflows and CI shell scripts.

**Files:** `.yamllint.yml`, `Infrastructure/ci/validate-workflows.sh`, `Infrastructure/ci/tests/validate-workflows_test.sh`

**Steps:**
1. Add contracts proving invalid YAML and shell fixtures are rejected.
2. Run actionlint, yamllint, and `bash -n` across repository workflow and CI files.
3. Validate repository files and emit focused diagnostics on failure.

**Duration:** 15m

**Dependencies:** CR-115, CR-116, CR-117

**Parallel:** No

**Definition of Done:** A single command rejects malformed fixtures and validates all checked-in workflows and CI scripts.
