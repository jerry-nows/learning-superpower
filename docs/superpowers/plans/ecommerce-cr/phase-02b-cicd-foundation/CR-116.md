# CR-116

**Objective:** Validate the self-hosted Apple Silicon iOS runner before CI work begins.

**Files:** `Infrastructure/ci/preflight-ios-runner.sh`, `Infrastructure/ci/tests/preflight-ios-runner_test.sh`

**Steps:**
1. Add fixture-based contracts for valid and invalid runner environments.
2. Verify arm64, Xcode 26.6, mise-managed Tuist and SwiftLint, Docker, and the configured Simulator.
3. Run the fixture contract and shell syntax validation.

**Duration:** 15m

**Dependencies:** CR-115

**Parallel:** Yes

**Definition of Done:** Preflight succeeds only on a runner with the required architecture, tools, Docker service, and available `iPhone 17` Simulator.
