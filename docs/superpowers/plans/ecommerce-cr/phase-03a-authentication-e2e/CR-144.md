# CR-144

**Objective:** Define the OpenAPI authentication contract.

**Files:** `Backend/api/openapi.yaml`

**Steps:**
1. Add login, refresh and logout request/response schemas.
2. Specify a 60-second access-token lifetime, opaque refresh token and bearer logout authorization.
3. Define stable `AUTH_*` error codes, trace ID, field violations and retryability.
4. Validate the document and reject examples containing real secrets.

**Dependencies:** CR-046

**Duration:** 15m

**Definition of Done:** OpenAPI precisely describes all Phase 3 auth requests, successes and errors.
