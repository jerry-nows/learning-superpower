# CR-141

**Objective:** Seed the deterministic local demo user.

**Files:** `Backend/cmd/seed/main.go`

**Steps:**
1. Add a command contract requiring email/password only from environment.
2. Hash the password with the production Argon2id hasher and upsert by normalized email.
3. Redact credentials from all logs and make repeated runs idempotent.
4. Run against local PostgreSQL twice and verify one user row.

**Dependencies:** CR-039, CR-137

**Duration:** 15m

**Definition of Done:** Local development can create one repeatable login account without committed credentials.
