# CR-157

**Objective:** Test the seeded-user login journey in XCUITest.

**Files:** `Apps/CommerceApp/UITests/LoginFlowTests.swift`

**Steps:**
1. Launch with an injected test endpoint and seeded credentials supplied outside source control.
2. Enter invalid credentials and assert the localized accessible error.
3. Enter valid credentials and assert the LoginFeature emits authentication to the app root.
4. Relaunch with biometric stubbing and verify session reopen/fallback behavior.

**Dependencies:** CR-152, CR-156

**Duration:** 15m

**Definition of Done:** XCUITest proves invalid login, valid login and biometric fallback against the local stack.
