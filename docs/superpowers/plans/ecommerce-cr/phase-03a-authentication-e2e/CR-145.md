# CR-145

**Objective:** Test the backend authentication lifecycle end to end.

**Files:** `Backend/integration/auth_lifecycle_test.go`

**Steps:**
1. Start migrated PostgreSQL and authenticated Redis containers.
2. Seed a hashed user and serve the real HTTP router with deterministic clocks/keys.
3. Exercise login, access expiry, refresh rotation, old-token reuse, family revocation and logout.
4. Assert stable error codes and run the complete test under `go test -race`.

**Dependencies:** CR-042, CR-045, CR-136, CR-138, CR-140, CR-142, CR-144

**Duration:** 15m

**Definition of Done:** One integration test proves login → rotation → reuse revocation → logout against real stores.
