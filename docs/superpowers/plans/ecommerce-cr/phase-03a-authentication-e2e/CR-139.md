# CR-139

**Objective:** Implement the Redis refresh-session repository.

**Files:** `Backend/internal/auth/redis_refresh_repository.go`

**Steps:**
1. Define repository expectations in CR-140 before implementation.
2. Store only refresh-token hashes with family ID, user ID, expiry and rotation state.

4. Apply bounded operation timeouts and return typed auth errors.

**Dependencies:** CR-043, CR-134

**Duration:** 15m
